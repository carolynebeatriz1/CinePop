Como o sistema é dividido

Os 3 microsserviços

1
Cartaz de filmesclass CartazCREATE TABLE filmesCREATE TABLE horarios

Guarda os filmes, horários, salas e preços.

2
Mapa de poltronasclass PoltronasCREATE TABLE ingressosocupadas() · reservar()

Mostra as ocupadas e reserva as escolhidas.

3
Pagamento simuladoclass PagamentoCREATE TABLE comprasgerar_codigo() · pagar()

Gera o código do ingresso e registra a compra.

self.banco = sqlite3.connect("cinepop.db") → Cartaz(banco) · Poltronas(banco) · Pagamento(banco)

Herança e polimorfismo

class Tela(tk.Canvas)
classe mãe: barra de etapas, botões, cartaz
TelaFilmesdesenhar()
TelaSessaodesenhar()
TelaPagamentodesenhar()
TelaIngressodesenhar()
class Tela(tk.Canvas): # mãe def desenhar(self): pass class TelaFilmes(Tela): # filha def desenhar(self): ... # a sua def mostrar(self, classe_tela): self.tela = classe_tela(self) self.tela.desenhar() # qualquer uma
Herançaclass TelaFilmes(Tela): herda botões, cabeçalho e cantos redondos sem repetir código.
PolimorfismoO mostrar() chama desenhar() sem saber qual tela é, e cada uma desenha a sua.
